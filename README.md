# Doctor Tracker — Frontend

Modern administrative portal for **Doctor Tracker** built with Next.js (App Router), TypeScript, Tailwind CSS, Lucide React, and Recharts.

## Features
- Next.js App Router with TypeScript
- Responsive layout (Sidebar & Topbar)
- Interactive Dashboard with Recharts
- Doctor & Patient management tables with search, filtering, and pagination
- Secure JWT-based route protection

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Environment Variables
Copy `.env.example` to `.env.local`:
```bash
cp .env.example .env.local
```

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for Production
```bash
npm run build
npm start
```
